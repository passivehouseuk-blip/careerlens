# Concept illustrations

The images are explanatory assets generated with **Nim / Nano Banana Pro**, requested at 2K / 16:9. Masters were 2752 × 1536 JPEGs; the documentation uses complete-frame 1600px WebP derivatives. Each selected image was downloaded and visually reviewed.

These are not real application screenshots, candidate records, approved ATS templates or evidence of successful hiring. Generated labels and connector paths illustrate a concept rather than an exact field-mapping specification. The screening picture's columns are not a recommendation for an exported resume layout. Placeholder text carries no real career claims.

The application has not been implemented. Pictures must retain an adjacent concept caption wherever they are reused as product documentation.
