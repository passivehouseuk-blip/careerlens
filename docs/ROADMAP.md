# Development direction

All implementation stages are planned. The current repository contains documentation and concept illustrations only.

1. **Product definition — documented.** Candidate problem, intended capabilities, initial boundaries and illustrative workflow.
2. **Reviewed profile — planned.** Import and manual entry, missing-field questions, evidence and explicit candidate review.
3. **CV preparation — planned.** Professional Lenses, truthful wording, document preview and export validation.
4. **Screening preparation — planned.** Vacancy criteria, supported terminology, readable document content and explainable gaps.
5. **Assisted applications — planned.** Cover letters, supported fields, exact review and separate preparation/submission states.
6. **Tracking and privacy — planned.** Campaigns, confirmed outcomes, candidate isolation and explicit external-processing boundaries.
7. **Release acceptance — planned.** Tested setup instructions, actual interface screenshots, security and privacy checks, licenses and a clear statement of supported platforms.

No dates, release numbers or integration commitments have been assigned. A phase becomes available only after implementation and verification; documentation publication does not advance its status.
