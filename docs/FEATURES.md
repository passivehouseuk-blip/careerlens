# Intended scope and acceptance expectations

This is a specification summary. None of the application behaviour below is implemented in this repository.

| Capability | Acceptance expectation before it may be described as available |
| --- | --- |
| Guided CV completion | A person can review imported information, answer missing-field questions and correct every generated suggestion before export. |
| Factual wording | Every included claim is traceable to a reviewed fact; missing information is not guessed. |
| ATS preparation | The exact exported document is checked for readable content, section structure and consistency with the approved facts. A check is not described as an employer's pass/fail decision. |
| Vacancy comparison | Each assessment distinguishes supported experience, missing evidence and hard requirements; unknown conditions remain unknown. |
| Relevant terminology | Suggested terms refer to genuine skills or experience; no hidden text or unrelated keyword insertion. |
| Professional Lenses | Focused, Standard and Extended selections preserve original titles and dates; exclusions apply to summaries, skills, projects and letters as well as experience. |
| CV and cover-letter generation | The candidate can inspect the complete result and choose its scope before sharing it. |
| Assisted form filling | Supported fields use reviewed data; unsupported questions and personal declarations are left for the candidate. Filling a form does not create a submitted status. |
| Approval | The exact recipient, vacancy, message, answers and CV version are visible; changes invalidate previous approval. |
| Submission tracking | Preparation, approval, transport and confirmation have distinct states. Unknown delivery is reconciled before another send. |
| Candidate isolation | One candidate cannot access another candidate's private record, documents, campaigns or approvals. |
| Market data | Sources, collection dates and coverage are visible. Published salaries are distinguished from estimates. |
| Analytics | Reports show observed counts and sample sizes; absent evidence is not converted into a predicted success rate. |
| External processing | Personal-data transfers, hosted storage and integrations are disclosed and controlled before use. |

## Initial boundaries

The first implementation should focus on profile completion, CV preparation, screening-readiness review, assisted applications and tracking. Universal browser submission, stealth automation, fabricated qualifications and interview guarantees are outside this scope.

Pictures describe a proposed product. They must not be used as evidence that any acceptance condition has passed.
